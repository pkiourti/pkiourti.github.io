In the IARPA TrojAI program at SRI International, I built a novel backdoor detection
method for image classifiers (**96% AUC**).

With MISA {% cite kiourti2021misa %}, we proposed an online defense that detects trojan
triggers at runtime using explainability (attribution) signals.
